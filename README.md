Taskora – Task Management Dashboard

Taskora is a full-stack Task Management Dashboard designed to help teams organize, assign, and track tasks efficiently. The application provides role-based access where Admins can manage tasks and Users can view and update their assigned work in real time.

Deployed Link :- https://taskora-t65b.vercel.app/

✨ Features
🔐 Authentication & Authorization
User Signup & Login
Role-based access control (Admin/User)
Secure authentication using JWT


👨‍💼 Admin Features
Create tasks
Assign tasks to users
Update task details
Delete tasks
Monitor task statistics


👨‍💻 User Features
View assigned tasks
Update task status
Track pending and completed work
📊 Dashboard Features
Task statistics overview
Pending, Completed & Overdue filters
Responsive modern UI
Real-time task updates
